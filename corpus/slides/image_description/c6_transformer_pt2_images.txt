[第2頁, 圖片1] ALBERT 的 Cross-Layer (Block) Parameter Sharing 概念，右側包含三個並排的 Transformer encoder 堆疊結構圖，分別標示為「attention parameters sharing」、「FFN parameters sharing」和「all parameters sharing」三種不同的參數共享策略。每個堆疊由多層 encoder block 組成，包含 multi-head attention、add & norm、feed forward network 等模組，從底部的 input embedding 開始向上傳遞至 output。不同共享策略中，被共享的模組以紅色虛線框標示，而非共享部分則以藍色虛線框標示。左側文字說明每個 encoder block 的前向傳播與後向傳播使用相同的權重矩陣，並標注 Attention parameter 的 Q、K、V 計算公式（Q = X * W_q, K = X * W_k, V = X * W_v），其中紅色文字標示「Shared across layers」表示這些參數在所有層之間共享。

[第3頁, 圖片1] 延續 Cross-Layer Parameter Sharing 的三個 Transformer encoder 堆疊結構圖（attention parameters sharing、FFN parameters sharing、all parameters sharing），與第2頁相同的視覺化呈現。左側文字討論「參數變少 = 運算變快？」的問題，說明 ALBERT 的 Lite 指的是參數量（記憶體）大幅減少，但運算量（FLOPs）與推論時間並沒有減少，因為資料在前向傳播時仍需走完所有 Encoder block 的矩陣運算。

[第7頁, 圖片1] Factorized Embedding Parameterization 的概念。左下方為 BERT 模型架構圖，顯示一個完整的 BERT 處理流程：底層為輸入 token（[CLS], Tok 1, Tok 2, ..., Tok N），經過 embedding 層（E_[CLS], E_1, E_2, ..., E_N）進入 BERT 主體，最後產生輸出（C, T_1, T_2, ..., T_N），其中 C 上方標有 Class Label 箭頭。右上方展示 BERT 的傳統嵌入矩陣示意圖，為一個淺藍色的 V x H 矩陣，列標籤為詞彙（I, am, a, student），表示對於每個 V 的嵌入需要儲存 H 值，產生 V*H 的嵌入矩陣。文字說明 BERT 會在嵌入層將單詞轉為固定大小的向量，對於大詞彙量的模型，詞嵌入層會有非常大的參數矩陣。

[第8頁, 圖片1] Factorized Embedding Parameterization 的完整對比圖。左側與第7頁相同的 BERT 架構圖和 V x H 嵌入矩陣。右側新增了 ALBERT 的解決方案：一個較小的淺藍色 V x E 矩陣（列標籤同為 I, am, a, student）旁邊乘以一個 E x H 的矩陣，中間以「x」符號連接。中央有一個粗黑箭頭從左指向右，上方標示紅色文字「為了減少參數」，下方說明 factorized embedding parameterization 的概念：將每個詞映射到一個遠小於隱藏層的維度空間，引入中間嵌入層 (E)，透過因式分解變成較小的矩陣。此圖清楚對比了 BERT 的 V x H 大矩陣與 ALBERT 的 V x E + E x H 因式分解方式。

[第20頁, 圖片1] TinyBERT 知識蒸餾的架構圖。左側為 Teacher (BERT) 模型，以藍色圖示呈現，由底部的 Text Input 開始，經過藍色矩形的 Embedding Layer，向上堆疊 N 層藍色六邊形的 Transformer Layer（維度為 d），頂部為藍色五邊形的 Prediction Layer。右側為 Student (TinyBERT) 模型，以紅色圖示呈現，結構類似但層數較少（M 層，M < N），維度較小（d'，d' < d）。中間以多條黑色箭頭連接兩個模型，標示「Transformer Distillation」，表示從 Teacher 的各層蒸餾知識到 Student 對應層。圖片右上角有圖例說明：六邊形代表 Transformer Layer、矩形代表 Embedding Layer、五邊形代表 Prediction Layer，並註明 Layer Number: N > M，Hidden Size: d > d'。底部 Text Input 同時連接到兩個模型。

[第22頁, 圖片1] ELECTRA 的 Replaced Token Detection (RTD) 預訓練流程圖。流程從左到右分為兩階段：首先是 Generator（typically a small MLM），輸入序列「the, chef, cooked, the, meal」中的部分 token 被替換為 [MASK]（the -> [MASK], cooked -> [MASK]），Generator 對被 mask 的位置生成替代詞（sample 出 the, ate 等詞）。接著是 Discriminator (ELECTRA)，接收 Generator 的輸出序列「the, chef, ate, the, meal」，對每個 token 進行二元分類，判斷其為 original（原始）或 replaced（被替換），輸出標籤分別為 original, original, replaced, original, original。此圖說明 ELECTRA 將 MLM 預訓練改為替換 Token 檢測任務。

[第23頁, 圖片1] ELECTRA 的完整詳細架構圖。左側為綠色背景的 Generator 部分：Original Input 序列「stress, alters, immune, system, response」經過 15% Random Masking 後變為「stress, [MASK], immune, system, [MASK]」，通過 Embedding Layer（Token Embeddings + Type Embeddings + Positional Embeddings）和 Embedding Projector，進入 L=12 層的 Transformer block 堆疊（藍色圓形表示），最後經過 Generator Predictor 輸出 Generator Output。右側為橙色背景的 Discriminator 部分：接收 Generator Output 序列「stress, increases, immune, system, processes」，通過共享的 Embedding Layer（Embedding Weight sharing 標示於兩者之間），進入 L=12 層的 Transformer block 堆疊（橙色圓形表示），經過 Discriminator Predictor 輸出每個 token 的 Original/Replaced 判斷結果。兩側 Transformer 都標示維度為 (B, MSL, H)。

[第27頁, 圖片1] GPT 與原始 Transformer Decoder 的架構對比圖。左側標示「(a) Original Transformer Decoder」，由底部 Text & Position Embed 開始，依序向上為 Masked Multi-Head Attention、Add&Norm、Multi-Head Attention、Add&Norm、Feed Forward、Add&Norm、Linear、Softmax，各模組以不同顏色的方塊表示（紫色、藍色、綠色、橙色、黃色等）。右側標示「(b) GPT Transformer Decoder (GPT-1)」，結構經過簡化：由底部 Text & Position Embed 開始，依序為 Masked Multi-Head Attention、Layer Norm、Feed Forward、Layer Norm、Text & Position Embed，移除了原始 Decoder 中的 cross-attention（Multi-Head Attention）模組，並將 Add&Norm 改為 Layer Norm 加上殘差連接（以加號符號表示）。此圖說明 GPT 基於 Transformer 的 Decoder 架構但移除了 cross-attention。

[第28頁, 圖片1] 延續展示 GPT 架構對比圖（與第27頁相同的兩個 Decoder 結構圖），左側增加了詳細的文字說明 Transformer decoder 與 GPT 的處理過程對比。Transformer decoder 處理過程包含 Masked Multi-Head Attention 關注之前序列、Multi-Head Attention (cross-attention) 抓取輸入句子的上下文、重複迭代等步驟。GPT 的處理則簡化為只使用 Masked Multi-Head Attention 關注之前序列，每生成一個詞就考慮之前所有的詞。

[第29頁, 圖片1] BERT 的 Self-Attention 與 GPT 的 Masked Self-Attention 的視覺化對比圖。左側標示「Self-Attention」並註明「BERT(Self-Attention)」，顯示一個序列中某個位置（以灰色圓點標示）可以關注到序列中所有位置的 token，注意力範圍以淺藍色三角形覆蓋整個輸入序列（底部的彩色方塊），上方的圓角矩形表示經過 attention 處理後的表示。右側標示「Masked Self-Attention」並註明「GPT(Masked Self-Attention)」，同樣顯示一個序列位置的注意力範圍，但淺藍色三角形只覆蓋當前位置及其左側的 token，右側的 token 以灰色方塊表示被遮蔽，說明 GPT 只能看到當前及之前的 token。此圖直觀展示了雙向注意力與單向遮蔽注意力的核心差異。

[第30頁, 圖片1] GPT-1 的 Next Token Prediction 流程圖。中央為一個垂直排列的管線圖，從底部到頂部依序為：Input（淺藍色）、Pre-trained language Model (Decoder)（淺黃色）、Linear（淺橙色）、Softmax（淺橙色）、Output（淺灰色）。右側並列展示 GPT-1 Transformer Decoder 的內部結構：由 Text & Position Embed 開始，經過 Masked Multi-Head Attention、Layer Norm（加殘差連接）、Feed Forward、Layer Norm（加殘差連接），最後到 Text & Position Embed，各模組以紅色線條連接標示對應關係。左側文字說明生成步驟：1. 經由 Decoder 生成下一個可能的詞向量，2. 通過線性層轉為 Logits 分數，3. 通過 softmax 轉換為機率分佈，並列舉了四種採樣策略：Greedy Search、Random Sampling、Top-k Sampling、Temperature Scaling。

[第38頁, 圖片1] InstructGPT 訓練方法的第一步驟 Supervised Fine-Tuning (SFT)。右側為 OpenAI 官方的 Step 1 流程圖，標題為「Supervised Fine-Tuning」，使用約 13K training prompts。流程由上而下：首先從 prompt dataset 中抽樣一個 prompt（範例為「Explain the moon landing to a 6 year old」，以綠色對話框圖示），接著由 labeler 示範期望的輸出行為（範例為「Some people went to the moon...」，以筆記圖示），最後使用此資料以監督式學習 fine-tune GPT-3（以 SFT 網路圖示和文件圖示表示）。左側文字說明 SFT 的三個要點：標註人員撰寫高品質標準回答、將問題+解答配對資料加入訓練、模型學習從預測下一個字轉變為遵循指令。

[第39頁, 圖片1] InstructGPT 訓練方法的第二步驟 Reward Modeling。右側為 Step 2 流程圖，標題為「Reward Modeling」，使用約 33K training prompts。流程由上而下：首先從 prompt 產生多個模型輸出（以四個圓角方塊 A、B、C、D 表示，分別為「Explain gravity...」、「Explain war...」、「Moon is natural satellite of...」、「People went to the moon...」），接著由 labeler 將輸出從最佳到最差排名（以人形圖示和排序 D > C > A = B 表示），最後使用排名資料訓練 Reward Model（以 RM 網路圖示和排序結果表示）。左側說明人類老師針對同一問題的多個回答進行好壞排名，用於訓練 Reward Model 學會人類的評分標準。

[第40頁, 圖片1] InstructGPT 的 Reward Model 訓練範例。頁面包含三個灰色文字框，分別標示為 #1、#2、#3，都回答同一問題「請給出五月天三首與『人生』有關的歌曲？」。#1 的回答為《第二人生》、《人生海海》、《一半人生》；#2 的回答為《志明與春嬌》、《人生海海》、《倔強》；#3 的回答最為詳細，包含每首歌曲的描述說明。底部紅色文字標示排序結果：#3 > #2 > #1，說明如果我們是老師，會依照回答品質給予這樣的排序並回饋到模型中。

[第41頁, 圖片1] InstructGPT 訓練方法的第三步驟 Reinforcement Learning。右側為 Step 3 流程圖，標題為「Reinforcement Learning」，使用約 31K training prompts（Only API）。流程形成一個循環：首先從 dataset 抽樣新的 prompt（「Write a story about frogs」），由 policy（PPO 網路圖示）生成輸出（「Once upon a time...」），接著 reward model（RM 網路圖示）計算獎勵分數（r_k），獎勵被用於通過 PPO 更新 policy。左側文字說明 PPO (Proximal Policy Optimization) 是一種強化學習策略，模型不斷嘗試生成新的對話並根據結果調整回答方式，目標是獲得最高分數。

[第48頁, 圖片1] Mixture of Experts (MoE) 的架構圖。圖示從底部到頂部的流程為：粉色的 Input 方塊向上連接到 Gating Network（以圓圈表示），Gating Network 向上分出多條連線（以黑色粗箭頭和灰色細箭頭表示不同權重）連接到一排 Expert 方塊（Expert 1、Expert 2、Expert 3、...、Expert n），各 Expert 的輸出向上匯聚，經過由 Gating Network 生成的 Weights（以圓圈和「Weights Generated By Gating Network」標示）加權後，最終到達頂部的 Output 方塊。右側文字說明 Experts 是將神經網路拆分成多個獨立的子網路，每個專家會專精處理某種類型的任務；Router / Gating Network 是一個輕量級的網路，負責指派任務，針對每一個 Token 決定應該交給哪幾個專家處理。

[第49頁, 圖片1] MoE 與 Ensemble Learning 的對比圖。左側為「Ensemble」架構：底部為橢圓形的 Input，向上直接連接到所有 Expert（Expert 1、Expert 2、...、Expert N），所有 Expert 的輸出再匯聚到頂部橢圓形的 Output，所有連線權重相同（以藍色細線表示），代表所有模型都參與運算。右側為「MoE」架構：底部為橢圓形的 Input，先經過方形的 Router 模組，Router 選擇性地將輸入路由到部分 Expert（Expert 1 以深灰色表示被選中激活，其餘為白色），被選中的 Expert 輸出連接到頂部的 Output。右下角 Note 說明 Ensemble 通常是把各自訓練好的模型湊再一起投票，而 MoE 的 experts 和 router 則是在同一個網路裡訓練。

[第53頁, 圖片1] T5 (Text-to-Text Transfer Transformer) 的統一框架示意圖。中央為一個大型的「T5」標誌方塊，左側有四個不同顏色的文字框作為輸入，分別以不同顏色區分不同任務：綠色框為翻譯任務（「translate English to German: That is good.」）、粉色框為語法判斷任務（「cola sentence: The course is jumping well.」）、黃色框為語義相似度任務（「stsb sentence1: The rhino grazed on the grass. sentence2: A rhino is grazing in a field.」）、藍色框為摘要任務（「summarize: state authorities dispatched emergency crews tuesday to survey the damage after an onslaught of severe weather in mississippi...」）。右側對應四個輸出框：綠色為「Das ist gut.」、粉色為「not acceptable」、黃色為「3.8」、藍色為「six people hospitalized after a storm in attala county.」。所有輸入透過黑色連線匯入 T5，所有輸出從 T5 延伸出去，展示 T5 將所有 NLP 任務統一為 text-to-text 格式的設計理念。
