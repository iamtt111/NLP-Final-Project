[第3頁, 圖片1] Named Entity Recognition（命名實體辨識）範例圖。句子「Steve Jobs was the CEO of Apple, headquartered in the state of California.」中，「Steve Jobs」以粉色框標記為 PER（人名），「Apple」以藍色框標記為 ORG（組織），「California」以綠色框標記為 LOC（地點）。此圖展示 NER 如何從文本中識別並分類命名實體。

[第4頁, 圖片1] NER 的挑戰說明表格。上方列出五大挑戰：實體跨越多個詞元、同一詞在不同語境代表不同實體類別、中文斷詞困難、新詞難以預測、資料高度不平衡。下方為 BIO 標記範例表格，句子「Steve Jobs really liked to wear black turtlenecks.」的每個詞元對應標籤：Steve = B-PER、Jobs = I-PER，其餘詞（really、liked、to、wear、black、turtlenecks）皆標記為 O（非實體）。

[第6頁, 圖片1] NER 模型演進流程圖。列出三個階段：1. 傳統模型（CRF、HMM，依賴人工特徵如 POS、位置等）；2. 深度學習模型（BiLSTM + CRF，引入上下文但需大量訓練資料）；3. Transformer-based 模型（BERT + CRF / linear classifier，利用 contextual embedding 提升準確率）。下方有簡易流程圖：BERT → Token Embeddings → 分支至 Classifier 或 CRF。

[第9頁, 圖片1] BIO Format（BIO 標記格式）說明表格。B 代表實體的開頭（Begin），I 代表實體的內部（Inside），O 代表非實體（Outside）。範例句子「Steve Jobs was the CEO of Apple headquartered in Silicon Valley」的標記：Steve = B-PER、Jobs = I-PER、was/the/CEO/of = O、Apple = B-ORG、headquartered/in = O、Silicon = B-LOC、Valley = I-LOC。

[第56頁, 圖片1] Contrastive Learning（對比學習）訓練過程視覺化，包含兩張二維空間散佈圖。上圖為 Step 0（初始狀態），Contrastive Loss = 2.45，三個點（錨點 Anchor 白色、正樣本 Positive 藍色、負樣本 Negative 粉色）距離相近且混雜，藍色箭頭標示「吸引相似特徵（Pulling）」，虛線箭頭標示「排斥相異特徵（Pushing）」。下圖為 Step 100（訓練後），Contrastive Loss = 0.25，正樣本與錨點靠近（上方），負樣本被推遠至下方，展示對比學習成功將相似樣本拉近、相異樣本推遠的效果。
