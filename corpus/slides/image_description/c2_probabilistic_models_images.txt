[第5頁, 圖片1] 計算序列機率時的關鍵公式與紅色註解說明。頁面包含 chain rule of probability 的展開式 p(x_1, x_2, ..., x_T) = p(x_1) * p(x_2|x_1) * p(x_3|x_1, x_2) * ... * p(x_T|x_{T-1}, ..., x_1)，以及使用 product notation 的等價寫法。底部以紅色文字標註 Key Computational Problem，並附有紅色註解方塊指出「Calculating this probability can be a nightmare when T becomes large due to data sparsity」，用箭頭指向條件機率 p(x_t | x_{t-1}, x_{t-2}, ..., x_1)，強調當序列長度 T 增大時資料稀疏導致計算困難的問題。此圖的教學目的是說明為何需要 Markov assumption 來簡化序列機率計算。

[第7頁, 圖片1] Markov Property 的圖解，包含一個由左至右的 Markov chain 示意圖。圖中有五個灰色圓形節點，分別標記為 x_{t-2}、x_{t-1}、x_t、x_{t+1}、x_{t+2}，節點之間以單向箭頭連接，表示狀態間的依序轉移關係。鏈的兩端各有一個箭頭延伸至圖外，暗示序列可無限延續。頁面下方顯示 joint probability 在 Markov property 下的簡化公式 p(x_1, ..., x_T) = p(x_1) * product_{t=2}^{T} p(x_t | x_{t-1})，說明每個狀態只依賴前一個狀態。此圖的教學目的是視覺化展示 first-order Markov chain 的結構與其對 joint probability 的簡化效果。

[第8頁, 圖片1] 以大型數學公式搭配綠色註解方塊展示 Markov property 的核心意義。上半部顯示公式 p(x_t | x_{t-1}, x_{t-2}, ...) = p(x_t | x_{t-1})，右上方有一個綠色圓角方塊標註「What the Markov property says」。下半部以斜體數學字型寫出 x_t is independent of x_{t-2}, x_{t-3}, ...，右側有另一個綠色方塊標註「What the Markov property also says」。兩個綠色方塊作為視覺標籤，幫助讀者理解 Markov property 的兩種等價表述：條件機率只依賴前一狀態，以及當前狀態與更早的歷史狀態條件獨立。

[第10頁, 圖片1] 展示天氣狀態轉移的 Markov Model 圖解。右下方有一個狀態轉移圖（state transition diagram），包含三個橢圓形節點：Sunny、Cloudy 和 Rainy。每個節點都有自環箭頭標示自身轉移機率（Sunny: 0.8, Cloudy: 0.5, Rainy: 0.6），節點之間以有向箭頭連接並標示轉移機率值：Sunny 到 Cloudy 為 0.15，Cloudy 到 Sunny 為 0.2，Sunny 到 Rainy 為 0.05，Rainy 到 Sunny 為 0.2，Cloudy 到 Rainy 為 0.3，Rainy 到 Cloudy 為 0.2。此圖以天氣為例具體說明 Markov Model 中 categorical symbols（狀態）之間的轉移機率結構。

[第16頁, 圖片1] 標題為「Initial State」，展示了一個視覺化範例來說明初始狀態分佈的概念。頁面中央有一個長方形文字框，內含句子「The quick brown fox jumps over the lazy dog.」，其中第一個單詞「The」被一個紅色小方框框選標記。上方有一個綠色對話氣泡指向「The」，氣泡內容為「What's the probability of the first word?」。下方顯示 initial state distribution 的公式 pi_i = p(s_1 = i) (for i = 1...M)。此圖的教學目的是以具體句子範例說明為何需要 initial state distribution 來量化序列中第一個狀態（單詞）出現的機率。

[第18頁, 圖片1] 標題為「Probability of a Sequence」，展示三個層次的數學公式推導，並搭配綠色註解方塊。第一行展示 chain rule 展開式 p(s_{1...T}) = p(s_1)p(s_2|s_1)p(s_3|s_1, s_2)...。第二行應用 Markov Property 將其簡化為 p(s_{1...T}) = p(s_1) * product_{t=2}^{T} p(s_t|s_{t-1})，右側有一個綠色方塊標註「Markov Property」。第三行進一步用矩陣符號表示為 p(s_{1...T}) = pi_{s_1} * product_{t=2}^{T} A_{s_{t-1}, s_t}，右側有一個較大的綠色方塊提示「Start thinking about how you'd implement this in Python code」。此圖展示從一般序列機率到 Markov Model 參數化表示的完整推導過程。

[第19頁, 圖片1] 標題為「Estimating A and pi (Training)」，以視覺化佈局展示 Markov Model 的參數估計公式。上半部顯示 initial state distribution 的估計公式 hat{pi}_i = count(s_1 = i) / N，左側有一個灰色圓角方塊標註「Note: the 'hat' means 'estimate'」，右上角有另一個灰色方塊說明「N = number of sequences in dataset」。下半部顯示 state transition matrix 的估計公式 hat{A}_{ij} = count(i -> j) / count(i)，右下角有灰色方塊舉例「Example: count("the cat") / count("the")」。四個灰色註解方塊分佈在公式周圍，形成清晰的視覺說明結構，幫助理解 maximum likelihood estimation 的直覺意義。

[第22頁, 圖片1] 標題為「Add-One Smoothing」，展示 Laplace smoothing 的公式及視覺化註解。中央顯示 add-one smoothing 後的 transition matrix 估計公式 hat{A}_{ij} = (count(i -> j) + 1) / (count(i) + M)，公式以大型數學排版呈現。右下方有一個灰色圓角方塊，內容為「Adding M to the denominator ensures that each row of A sums to 1」，提供重要的數學直覺說明。此頁的教學目的是解決零機率問題，透過在分子加 1、分母加 M 的方式確保每個轉移都有非零機率，同時維持機率分佈的合法性。

[第26頁, 圖片1] 標題為「Working with Log Probabilities」，展示對數函數圖表來說明使用 log probability 的動機。頁面下半部包含一個座標圖，x 軸範圍從 1 到 11，y 軸範圍從 -4 到 4，圖中繪製了三條對數曲線：深藍色的 log_2(x)、橘色的 ln(x)（自然對數），以及紅棕色的 log(x)（常用對數）。三條曲線在 x = 1 處交於 y = 0，x < 1 時趨向負無窮。圖中以藍色虛線標示 x = 0 的漸近線。此圖的教學目的是視覺化說明 log 函數是單調遞增函數，因此取 log 不會改變大小比較的結果，支持用 log probability 取代直接機率乘法以避免數值下溢問題。
