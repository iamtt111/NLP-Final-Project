[第59頁, 圖片1] 標題為「LSTM (Long Short-Term Memory)」，並排展示 RNN、LSTM 和 GRU 三種循環單元的內部結構比較。左側為最簡單的 RNN，僅包含一個 tanh 運算。中間為 LSTM，結構最為複雜，包含 forget gate (f_t)、input gate (i_t)、output gate (o_t)，以及 cell state 候選值，內部有多個 sigma 和 tanh 節點，cell state (c_t) 以水平線在頂部傳遞。右側為 GRU，包含 reset gate (r_t) 和 update gate (z_t)，以及一個 1- 運算節點，結構介於 RNN 和 LSTM 之間。三者均以淺綠色背景繪製，粉紅色圓形標示各種門控運算節點，黑色箭頭標示資訊流向，清楚對比三種架構的複雜度差異。

[第60頁, 圖片1] 標題為「GRU vs LSTM」，以方塊圖比較 GRU 和 LSTM 的輸入輸出介面差異。左側為 GRU 方塊：輸入 x(t) 和 h(t-1)，輸出 h(t)，旁邊以紅色文字標示各端口含義——x(t) 為 Current word，h(t-1) 為 Short-term memory。右側為 LSTM 方塊：輸入 x(t)、h(t-1) 和 c(t-1)，輸出 h(t) 和 c(t)。紅色文字標示 c(t-1) 為 Long-term memory。此圖清楚展示 LSTM 比 GRU 多了一個 cell state (c) 作為長期記憶通道，是兩者最主要的結構差異。

[第61頁, 圖片1] 標題為「LSTM Equations」，以數學公式展示 LSTM 的完整運算方程式。圖中列出五個核心公式，右側以灰色文字標註每個公式對應的門控名稱：f_t = sigma(...) 對應 Forget gate、i_t = sigma(...) 對應 Input/update gate、o_t = sigma(...) 對應 Output gate、c_t = f_t * c_{t-1} + i_t * f_c(...) 為 cell state 更新（其中 f_c 標註為 tanh，並以引號標示此部分等同於 "Simple RNN"）、h_t = o_t * f_h(c_t) 為 hidden state 輸出（f_h 同樣標註為 tanh）。此圖完整呈現 LSTM 各門控的數學定義及其相互關係。
