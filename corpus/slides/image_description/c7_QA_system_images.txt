[第21頁, 圖片1] 此圖為 Retrieval Augmented Generation (RAG) 系統的完整架構圖。圖中由下而上展示了 RAG 的資料處理流程：最底層為 Text Documents（文字文件），以黃色方塊表示多個文件；這些文件經由 Embedding Model（灰色橫條區塊，帶有齒輪圖示）轉換為 Embeddings（深藍色方塊），共同組成 Vector Database（向量資料庫）。左側有一個紅色方塊代表 User Query（使用者查詢），同樣被轉為 embedding。中間層為 Nearest Neighbor Search（最近鄰搜尋，灰色橫條區塊），負責從所有 embeddings 中找出與查詢最相似的結果，產生 Nearest Neighbors（以深藍與黃色拼接的方塊表示）。最頂層為 LLM（大型語言模型，灰色橫條區塊），接收查詢與最近鄰結果後生成綠色的 Response（回應）。箭頭由下至上串聯整個流程，說明 RAG 如何結合檢索與生成來回答問題。

[第67頁, 圖片1] 此投影片標題為「如何融合？」，展示 Hybrid Search 中兩種融合方法的數學公式。上半部為 Weighted Fusion 方法，以灰色背景方框顯示公式 Final_Score = alpha * Dense_Score + (1 - alpha) * Sparse_Score，其中 alpha 為可調整的權重參數。下半部為 RRF (Reciprocal Rank Fusion) 方法，同樣以灰色背景方框顯示公式 RRF_Score(d) = sum over r in R of 1/(k + rank_r(d))，其中 R 為檢索器集合、r 為單一檢索器、rank_r(d) 為文件在檢索器中的排名、k 為平滑常數（通常為60）。
